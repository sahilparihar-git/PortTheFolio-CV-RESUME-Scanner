## 🚀 Overview

**PortTheFolio** is an advanced AI-powered tool designed to analyze Curricula Vitae (CVs) and Portfolios. It leverages the powerful **Google Gemma 3 12B** Large Language Model to provide granular scoring, identify rejection reasons, and suggest concrete fixes to improve ATS (Applicant Tracking System) compatibility.

## ✨ Features

-   **📄 Smart Document Analysis**: Instantly separates valid CVs from non-relevant documents.
-   **🤖 AI-Powered Scoring**: Receive a compatibility score (0-100) based on industry standards.
-   **🔍 Detailed Feedback**:
    -   **Rejection Analysis**: Understand exactly why a CV might be rejected.
    -   **Actionable Fixes**: Get step-by-step instructions (with examples) on how to improve.
-   **⚡ Modern Tech Stack**: Built with React, Vite, and TailwindCSS for a lightning-fast responsive UI.

## 🛠️ Tech Stack

-   **Frontend**: React, TypeScript, TailwindCSS, Shadcn UI
-   **Build Tool**: Vite
-   **AI Model**: Google Gemma 3 12B

## 🏎️ Getting Started

### Prerequisites
-   Node.js (v18+)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/sahilparihar-git/PortTheFolio-CV-Scanner.git
    cd PortTheFolio-CV-Scanner
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run Locally**
    ```bash
    npm run dev
    ```
    The app will start at `http://localhost:8080`.
